
# Exploratory Analyses

This directory contains additional exploratory analyses conducted during the
development of the study.

These analyses investigate related forms of contextual dependence using
variables and specifications outside the primary five-stage empirical analysis.
They are retained to document the broader analytical exploration surrounding
the Interaction-Analysis Framework and the development of the study's
contextual argument.

These materials are exploratory and are not part of the primary empirical
results reported in the paper.
