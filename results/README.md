# Analysis Results

This folder contains the principal outputs generated by the complete empirical analysis script.

## Files

### `dataset_overview.png`
Summary of the analysis dataset and its structure prior to the interaction analyses.

### `stage_1_genre_level_pooled_output.png`
Stage 1 output showing pooled Ads/IAP × genre interaction estimates for install success and rating success.

### `stage_2_cross_market_output.png`
Stage 2 output summarizing the interaction classifications across the 42 national markets for both success measures.

### `stage_3_temporal_output.png`
Stage 3 output summarizing the temporal interaction classifications across country–month contexts for both success measures.

### `stage_5_national_context_output.png`
Stage 5 output reporting the Spearman correlations between country-specific interaction magnitude and the five national-context indicators, including Benjamini–Hochberg FDR-adjusted p-values.

### `consolidated_summary_output.png`
Consolidated summary of the principal interaction results across the empirical analyses.

## Stage 4 Materials

Stage 4 — Gameplay Characterization involves game selection and manual gameplay characterization rather than a single statistical output table. Its methodology, selected-game lists, game-selection outputs, and supporting materials are provided separately in the `supplementary/gameplay characterization/` folder.
